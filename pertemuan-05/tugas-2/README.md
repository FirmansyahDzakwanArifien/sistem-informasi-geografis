# Pertemuan 5 — Tugas 2: Praktikum Mandiri QGIS

Project QGIS `praktikum_gis2` berisi area polygon DI Yogyakarta dan Kota Depok yang diimpor dari file KML menggunakan plugin KML Tools di atas peta dasar OpenStreetMap, lalu diekspor ke ESRI Shapefile.

| File | Keterangan |
|------|------------|
| [praktikum_gis2.qgz](praktikum_gis2.qgz) | Project QGIS (QGIS 4.2.3) |
| [wilayah-di-yogyakarta.kml](wilayah-di-yogyakarta.kml) | Data input: polygon DI Yogyakarta (WGS 84 / EPSG:4326) |
| [wilayah-kota-depok.kml](wilayah-kota-depok.kml) | Data input: polygon Kota Depok (WGS 84 / EPSG:4326) |
| `wilayah_di_yogyakarta.*` | Hasil ekspor ESRI Shapefile DI Yogyakarta |
| `wilayah_kota_depok.*` | Hasil ekspor ESRI Shapefile Kota Depok |
